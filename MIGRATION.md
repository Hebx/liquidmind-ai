## 🛠️ Step-by-Step Execution

### Phase 1: Target Environment Setup
```bash
# Update system
sudo apt update && sudo apt upgrade -y

# Install Node.js (via FNM)
curl -fsSL https://fnm.vercel.app/install | bash
fnm install 20

# Install Foundry (for contracts)
curl -L https://foundry.paradigm.xyz | bash
foundryup

# Install OpenClaw & PM2
npm install -g openclaw pm2
```

### Phase 2: Full Data Sync (Local -> VPS)
```bash
# Sync Global Config
rsync -avz ~/.openclaw/ user@vps-ip:~/.openclaw

# Sync Workspace
rsync -avz /Users/heb/clawd/ user@vps-ip:~/clawd
```

### Phase 3: Service Restoration
```bash
# Start Knowledge Graph Server
pm2 start "node ~/clawd/scripts/knowledge-graph/kg-server.mjs" --name "kg-server"

# Start OpenClaw Gateway
openclaw gateway start
```

### Phase 4: Project Activation (LIQUIDMIND)
```bash
cd ~/clawd/projects/liquidmind-ai/agents
npm install
pm2 start "npm run start:coordinator" --name "a2a-coordinator"
pm2 start "npm run start:specialists" --name "a2a-swarm"
```
